# Changelog

All notable changes to this project will be documented in this file.

The format is based on Keep a Changelog, and this project follows Semantic Versioning.

## [0.1.3] - 2026-02-17

### Added
- Added `LICENSE-MIT` and `LICENSE-APACHE` files to the repository.
- Added GitHub Actions CI workflow (`.github/workflows/ci.yml`).
- Added GitHub Actions publish workflow (`.github/workflows/publish.yml`).
- Added README badges for crates.io, docs.rs, license, and CI status.

### Changed
- Updated crate-level generated docs header to refer to CH57x instead of CH573.

## [0.1.2] - 2026-02-17

### Added
- Expanded crate metadata for crates.io/docs.rs (`readme`, `homepage`, `keywords`, `categories`).
- docs.rs build metadata with embedded target and explicit feature set.
- Crate-level docs now include README content for better docs.rs landing context.

### Changed
- Improved README with feature documentation and usage guidance.
